## Intent

Playtest feedback on the first update. Two bugs and four changes, all within SPEC CAP-10/CAP-11:

1. Bug: detaching the suppressor leaves it drawn on the held gun.
2. Bug: detaching plays no character animation.
3. The suppressor lies flat on the floor, not on end.
4. Shots sound suppressed while it is attached.
5. The tooltip no longer says "Never wears out" (the behaviour is unchanged).
6. The poster (and Workshop preview, which copies it) shows the suppressor detached, under the gun.

## Boundaries & Constraints

**Always:** changes apply to the PPK/S suppressor only; other guns' parts behave as vanilla. One sound rule next to the radius rule: suppressed -> sound radius 10 and `SwingSound = WaltherPPKS_ShootSuppressed`; otherwise 70 and `M9Shoot`. Reapplied wherever the radius is (attach/detach complete, equip, game start, player update).

**Never:** other new sounds, changes to stats or loot, wear.

## Code Map

Mod root `M = workshop/WaltherPPKS/Contents/mods/WaltherPPKS/42/media`.
- Vanilla `ISRemoveWeaponUpgrade`: empty `start()`, `complete()` never rebuilds hand models (attach does, via equipping the part and `setSecondaryHandItem(nil)`).
- `M/lua/shared/WaltherPPKS_Suppressor.lua` -- wrap `start()` (`Craft` anim, gun + suppressor as hand models), `perform()` (`resetEquippedHandsModels()` on a client), `OnPlayerUpdate` (rebuild when the held gun's suppressor state changes, for multiplayer sync); `apply` also sets the swing sound.
- `M/scripts/WaltherPPKS_suppressor.txt` `PPKSSuppressor_Ground` -- `world` attachment `rotate = 0 0 90`, offset x = +radius (vanilla `Handgun_Light_Ground` pattern: z 90 with a positive x lift).
- `M/scripts/WaltherPPKS_sounds.txt` -- new `sound WaltherPPKS_ShootSuppressed` (file clip).
- `M/sound/suppressed_pistol_shot.ogg` -- supplied by the mod author (Ogg Vorbis, stereo, 44.1 kHz, ~1 s).
- `M/lua/shared/Translate/EN/Tooltip.json` -- drop "Never wears out."
- `tools/build_box_art.py` `build_listing_images()` -- add the suppressor icon under the gun.

## Implementation Notes

- Detach: `ISRemoveWeaponUpgrade.start` wrapped (PPK/S suppressor only) -> `setActionAnim("Craft")`, `setOverrideHandModels(gun, suppressor)`; `perform` wrapped -> `character:resetEquippedHandsModels()` when `S.hasHandModels()` (not on a dedicated server). `OnPlayerUpdate` tracks `{item ID, radius}` per player and rebuilds hand models once when the held gun's state flips (multiplayer sync path).
- Ground model: `world` attachment `offset = 0.0088 0.0514 0`, `rotate = 0 0 90` (was `-0.0088 0.0514 0`, no rotation, so it stood on end). Pose sign taken from vanilla `Handgun_Light_Ground`; untested in game.
- Sound: `scripts/WaltherPPKS_sounds.txt` defines `sound WaltherPPKS_ShootSuppressed` in module Base (file clip `media/sound/suppressed_pistol_shot.ogg`, category Item, distanceMax 1000 like M9Shoot). `S.apply` sets `setSwingSound` alongside the radius. The file is stereo; FMOD may not position stereo files in 3D as well as mono, so check in game how it sounds from other players.
- Tooltip: "Walther PPK/S attachment. Greatly reduces the noise of each shot, drawing fewer zombies." Wear behaviour unchanged.
- Poster: suppressor icon at 4x (128px) at (34,106), under the barrel; `preview.png` copies it. Box texture/icon regenerated byte-identical.
- Dev checks added: detach anim/hand models (PPK/S only), perform and player-update model rebuild counts, server reports no hand models, shot sound swaps on attach/detach/equip/synced detach, M9 untouched, sound script exists, ground pose values. Clip-file check SKIPs: `GameSoundScript`/`GameSoundClip` methods aren't exposed to Lua.
- Server test: RESULT PASS (5189 passed, 0 failed), exit 0, no mod ERROR/WARN.
