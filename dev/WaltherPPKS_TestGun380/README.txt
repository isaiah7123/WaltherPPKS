Throwaway .380 test gun for CAP-4: proves another mod's gun can use the PPK/S ammo
(AmmoType waltherppks:bullets_380 / WaltherPPKS.Bullets380) with zero edits to the ammo files.

It also switches on the WaltherPPKS loot dump and runs automatic checks of the injected loot and
item stats. Look for "[WaltherPPKS]" and "[WaltherPPKS-TEST]" lines in the console / server log.

In game (debug mode): spawn WaltherPPKS_TestGun380.TestGun380 and WaltherPPKS.Bullets380, load, fire.
