A suppressor for the Walther PPK/S

Forge session, 5 November 2026 · Goal: test whether it holds up · Outcome: survived, and changed the mod’s identity

Locked decisions

  • LockPurpose is stealth. The PPK/S deliberately becomes Build 42’s only quiet gun.
  • LockSound radius 20 with the suppressor on (70 without; the M9 is 100).
  • LockRarity is the only limit: it never wears out and can’t be crafted.
  • LockSpawns copy the vanilla x8 scope’s rarity, in civilian spots only.
  • Lock“Realism decides every trade-off” stays, with the suppressor as its one named exception.
  • LockShips in the first update after version 1.
  • LockArt comes from MihaM’s CC BY model; one small Lua script changes the gun’s noise.

Rejected, and why

  • KilledRadius 30: you chose the near-silent 20.
  • KilledWearing out: a permanent find, and less code.
  • KilledHalf the x8 scope’s rarity: you wanted an exact match.
  • KilledSWAT and army spawns: it would turn up where its gun never does.
  • Killed“Gameplay first”: the suppressor is the only big departure.
  • KilledShipping it in version 1: untested code shouldn’t hold up the gun.

Weak points that survived

  • RiskOnce found, it’s permanently the best stealth gun. Rarity is the only brake.
  • RiskThe game’s code has setSoundRadius available to Lua, but it hasn’t been tried in game.
  • RiskThe copied spawn numbers won’t follow if the developers retune the x8 scope.
  • RiskThe suppressor in MihaM’s model is unconfirmed until download.
  • RiskThe gun model needs a muzzle attachment point, tested for floating or clipping.
